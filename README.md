# Gestor de Inventario (GestorInv)

Aplicación de gestión de inventario de abarrotes construida con React y Supabase.

## Configuración

### Crear la tabla en Supabase

Antes de ejecutar la aplicación, debes crear la tabla de productos en tu proyecto de Supabase:

1. Accede a tu proyecto de Supabase en https://supabase.com/dashboard
2. Ve al apartado "SQL Editor"
3. Ejecuta el siguiente script SQL para crear la tabla:

```sql
CREATE TABLE products (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  precioPublico DECIMAL(10, 2) NOT NULL,
  costoProveedor DECIMAL(10, 2) NOT NULL,
  cantidad INTEGER NOT NULL,
  sistemaMedida VARCHAR(50) NOT NULL DEFAULT 'unidad',
  fotoProducto TEXT,
  fotoCodigoBarras TEXT,
  procedencia VARCHAR(50) NOT NULL DEFAULT 'Estrellita'
);
```

### Instalar dependencias

```bash
npm install
```

### Ejecutar la aplicación

```bash
npm start
```

## Funcionalidades

- Registro de productos con nombre, precios, cantidades y fotografías
- Búsqueda de productos
- Edición y eliminación de productos
- Exportación a CSV y JSON
- Sistema de calificación de proveedores
- Almacenamiento de imágenes en Base64

## Tecnologías utilizadas

- React
- Supabase
- Tailwind CSS
- Lucide React (iconos)
